# Интеллектуальная поисковая система по внутренней базе знаний университета

Веб-приложение для полнотекстового поиска по внутренним документам университета с поддержкой извлечения текста, ранжирования результатов и мониторинга системы.

## Технологический стек
### Backend & API
* Язык и фреймворк: Python 3.12+, FastAPI.

* Обработка данных: pdfplumber (PDF), python-docx (DOCX), Pydantic 2.0 (валидация данных).

* Базы данных и поиск: PostgreSQL 15 (метаданные), Elasticsearch 8.11 (полнотекстовый поиск), Redis 7 (кэширование).

* ORM & Миграции: SQLAlchemy 2.0.

* Мониторинг: prometheus-fastapi-instrumentator.

### Frontend
* Язык: TypeScript, React.

* Сборка: Vite.

### DevOps & Инфраструктура
* Контейнеризация: Docker, Docker Compose.

* CI/CD: GitHub Actions (автоматизация проверок и тестов).

* Мониторинг: Prometheus + Grafana.

### Тестирование
* Unit/Integration: pytest, pytest-asyncio, httpx (тестирование API-запросов).

## Требования

Для запуска требуются: Docker Engine (версия 20.10+), Docker Compose (версия 2.0+), Git.

## Быстрый запуск одной командой

Для развертывания всего стека сервисов в изолированном Docker-окружении выполните команду в корневом каталоге:

```bash
docker compose up --build -d
```
Важно: Перед запуском убедитесь, что в корне проекта создан файл .env на основе примера .env.example. Бэкенд начнет работу автоматически только после того, как PostgreSQL и Elasticsearch пройдут внутренние проверки готовности (healthchecks).
## Скрипт автоматической инициализации данных
Для проверки системы подготовлен bash-скрипт init.sh, который скачивает 10 тестовых PDF-документов из открытых академических источников и загружает их в систему через бэкенд API.

Запуск скрипта на хост-машине:
```bash
chmod +x init.sh
./init.sh
```
Скрипт локально выполнит загрузку файлов, отправит их методом 
**POST /api/v1/documents/upload** на **localhost:8000**, проверит HTTP-статусы ответов бэкенда и очистит за собой временные файлы.
## Архитектура портов и доступные сервисы
* **Frontend Клиент:** http://localhost:3000 — Интерфейс поиска и Drag-and-Drop загрузки.

* **Backend REST API:** http://localhost:8000 — Сервис обработки данных.

* **OpenAPI Документация (Swagger):** http://localhost:8000/docs — Интерактивный UI для тестирования эндпоинтов.

* **Elasticsearch Engine:** http://localhost:9200 — Полнотекстовый поисковый движок.

* **Prometheus Сервер:** http://localhost:9090 — Сбор метрик производительности API.

* **Grafana Дашборд:** http://localhost:3001 — Визуализация метрик (логин: admin, пароль: admin).

Примечание: корневой путь http://localhost:8000 не имеет публичного интерфейса и возвращает **404**. Пожалуйста, используйте **/docs** для доступа к документации или **/api/v1/...** для работы с эндпоинтами.
